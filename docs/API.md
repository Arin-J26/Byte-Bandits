# Sniffer API

All endpoints live under `/api` on the same origin as the frontend (default http://localhost:8000).
Requests and responses are JSON. Errors look like `{"error": "message"}` (or, for validation errors, `{"error": "Invalid request", "details": [...]}`) with a matching HTTP status.

Every example below is real output, generated by `backend/scripts/make_examples.py` with seed 2026 (long lists are trimmed; full outputs are in `examples/output/`). Interactive docs: `/api/docs`.

## Contents

- `POST /api/simulate/load`
- `GET /api/health`
- `GET /api/projects`
- `GET /api/trust-edges`
- `GET /api/records`
- `POST /api/evaluate`
- `GET /api/campaigns`
- `POST /api/campaigns/{id}/suggest-denounce`
- `GET /api/events`
- `PUT /api/trust`
- `POST /api/records`
- `GET /api/network/export`
- `POST /api/network/import`

## `POST /api/simulate/load`

Replace all data with a seeded synthetic network. Body fields are optional. Accepts `projects` (20-50), `newcomers`, `campaign_size` (number of spam PRs), `seed`, or the frontend's `projectCount`/`campaignSize`, or `{"preset": "demo"}`.

**Request:**

```json
{
  "projects": 40,
  "newcomers": 8,
  "campaign_size": 38,
  "seed": 2026
}
```

**Response** `200`:

```json
{
  "ok": true,
  "seed": 2026,
  "projects": 40,
  "trust_edges": 68,
  "records": 94,
  "pr_events": 50,
  "spam_accounts": 13
}
```

## `POST /api/records`

**Request:**

## `POST /api/network/import`

Replace the network with an exported one (max 5 MB). Signatures are verified on import and `signature_valid` is recomputed.

**Request:**

```json
"<the JSON from GET /api/network/export>"
```

**Response** `200`:

```json
{
  "ok": true,
  "projects": 40,
  "trust_edges": 68,
  "records": 95,
  "invalid_signatures": 1,
  "pr_events": 50
}
```
